# Redesign mockups

iPhone mockups (393 pt wide, exported at 2x) for the light redesign: Today, Fitness, Live Workout, Biology and Coach.

- `01-today.png` … `05-coach.png`: the exported screens.
- `redesign.vectorcraft`: the VectorCraft document, one artboard per screen.
- `redesign.svg` and `generate.py`: the source the document was built from. To change a screen, edit `generate.py`, run `python3 generate.py redesign.svg`, open the SVG in VectorCraft, and set the artboards (x = 453 × index, widths 393, heights 1400 / 1330 / 900 / 950 / 880).

Type is Inter; colours match `App/Design/Theme.swift` (light).
